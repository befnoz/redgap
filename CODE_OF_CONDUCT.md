# Code of Conduct

This project follows the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/).

Be respectful. Assume good faith. No harassment, discrimination, or personal attacks. Keep discussion technical and constructive.

Because this is a security project, one extra rule: **do not use the issue tracker or pull requests to distribute weaponized code, real exploits, or techniques aimed at systems you do not own.** RedGap is a defensive coverage tool scoped to its own lab; contributions must stay within that scope (see [ETHICS.md](ETHICS.md) and [SCOPE.md](SCOPE.md)).

Report conduct concerns to the maintainer via a private channel (see [SECURITY.md](SECURITY.md)).
